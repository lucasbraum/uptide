# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticize code and ideas rather than people,
and accept that maintainers may edit or remove contributions and comments that do not meet
this standard. Harassment, personal attacks, and publishing someone's private information
are not acceptable anywhere in the project's spaces (issues, pull requests, discussions).

## Reporting

Report unacceptable behavior privately to the maintainers through
[private reports](https://github.com/uptide-dev/uptide/security/advisories/new), rather
than in a public thread. Reports are kept confidential, reviewed promptly, and handled
following the Covenant's enforcement
guidelines: correction, warning, temporary ban, permanent ban.
