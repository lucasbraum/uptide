# priorities

A synthetic application of public npm packages at versions with known advisories, a
deprecation and a dev-only test dependency, for `uptide list` PRIORITIES. `registry.json`
(versions and deprecation messages) and `advisories.json` (npm's bulk advisory response for
the installed versions) were recorded once from registry.npmjs.org; tests and report previews
serve them offline. Nothing here comes from a real project.
